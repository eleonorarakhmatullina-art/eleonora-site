# Сайт «Элеонора»

Полноценная фронтенд-платформа репетитора по физике, алгебре и геометрии для 6–10 классов.

## Запуск в VS Code
1. Распакуй `site-eleonora-full.zip`.
2. Открой VS Code.
3. File → Open Folder → выбери папку `site-eleonora`.
4. Открой `index.html`.
5. Для простого запуска: ПКМ по `index.html` → Open with Default Browser.
6. Рекомендуемый вариант: установи расширение **Live Server**, затем ПКМ по `index.html` → **Open with Live Server**.

## Демо-вход
`ivan / 1234` и `maria / 1234`.

## Возможности
Авторизация через localStorage, личный кабинет, прогресс изучения тем, заметки, теория, поиск тем, фильтры задач, решения, домашние задания, тёмная тема и адаптивная мобильная вёрстка.

Сервер и база данных не требуются: это полностью автономная демонстрационная версия.
